Cọ mặt nạ

Mặc định ra ảnh chụp thật (như máy ảnh/điện thoại), không phải tranh vẽ.

iPhone: vẽ ở 384/512 px rồi phóng nhẹ lên ~720 px cho đỡ RAM. Nếu Safari vẫn văng, hãy đóng hẳn các tab khác rồi thử lại, hoặc dùng máy tính.

Tải model của bạn

Hỗ trợ model ghép mặt (inswapper, hyperswap, simswap, ghost, uniface…) và model làm nét (GFPGAN, CodeFormer, GPEN, RestoreFormer) dạng .onnx. Không hỗ trợ model khiêu dâm/không kiểm duyệt.

iPhone: chọn file .onnx trong ứng dụng Tệp (Files). Có thể chọn kèm model.json và file .data.

Chỉ chạy trên Chrome/Edge máy tính. Ứng dụng quét mọi file .onnx (+ model.json nếu có).

Máy chủ phải cho phép CORS. Link Hugging Face dạng /resolve/ dùng được.
